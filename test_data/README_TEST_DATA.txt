GUI Testing Guide:
------------------

1. Volume Viewer (Phase 8B):
   - Open sphere_64x64x64_8bit.raw (dims: 64, 64, 64, 8-bit, 1 comp)
   - Test slice navigation (axial / sagittal / coronal)
   - Test window/level adjustment
   - Test 3-D ray-cast view toggle
   - Open rgb_sphere_64x64x64_8bit.raw (dims: 64, 64, 64, 8-bit, 3 comps)
   - Verify multi-component display

2. Codec Panel (Phase 8C):
   - Open sphere_64x64x64_8bit.raw, then encode to JP3D (lossless + lossy)
   - Open sphere_lossless.jp3d directly — should decode and display
   - Test transcode from EBCOT to HTJ2K

3. Round-trip Testing (Phase 8D):
   - Open shepp_logan_128x128x64_8bit.raw
   - Run one-click round-trip (encode → decode → diff)
   - Verify lossless: PSNR=inf, MSE=0, max-err=0
   - Switch to lossy 9/7 and verify PSNR / error map
   - Run batch test suite

4. Codestream Inspector (Phase 8D.4):
   - Open sphere_lossless.jp3d
   - Verify tree-view shows SOC, SIZ3D, COD3D, QCD3D markers
   - Inspect tile-part / packet structure

5. 3-D Volume Rendering:
   - Open heart_128x128x128_8bit.raw (dims: 128, 128, 128, 8-bit, 1 comp)
   - Toggle 3-D ray-cast view to see the anatomical heart
   - Adjust azimuth, elevation, and density sliders to explore
   - Visible structures: LV, RV, LA, RA, aorta, pulmonary artery
   - Open rgb_heart_128x128x128_8bit.raw for colour-coded anatomy
